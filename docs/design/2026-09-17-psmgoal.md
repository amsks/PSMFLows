# psmgoal: goal-indexed affine successor measure, amortised coefficient, in-support backup

Date: 2026-09-17. Status: spec; implementation by subagent; launch after smoke.

## Notation (fixed)

u action latent (5-d, flow preimage); u' next-action / policy index; s, s', s+ states; g goal
state; theta trained parameters. D = R^128.

    phi_theta : S x U x S+ -> D        b_theta : S x U x S+ -> R        (general networks on the triple;
                                                                          NO A/beta split, NO state basis)
    h_theta   : S+ -> D                w*(g) = h_theta(g) / ||h_theta(g)||
    l_theta   : S x U x S+ -> R>=0     per-triple multiplier (softplus output); optional
    M^{pi_g}(s,u,s+) = phi_theta(s,u,s+)^T w*(g) + b_theta(s,u,s+)
    r_g(s+) = 1[s+ = g]  =>  Q_g(s,u) = phi_theta(s,u,g)^T w*(g) + b_theta(s,u,g)
    pi_g(s) = G(s, u_g(s)),   u_g(s) = argmax over 8 prior draws u of Q_g(s,u)   (min over ensemble of 2)

## Objective and Lagrangian (per goal g, averaged over goals)

    max_theta  E_{(s,u)~D} [ phi(s,u,g)^T w*(g) + b(s,u,g) ]
    s.t.       phi(s,u,s+)^T w*(g) + b(s,u,s+) >= 0   for all (s,u,s+)

    L = - E_{(s,u)} [ phi(s,u,g)^T w*(g) + b(s,u,g) ]
        - sum_{(s,u,s+)} l(s,u,s+) * min( phi(s,u,s+)^T w*(g) + b(s,u,s+), 0 )

## Per-step optimisation (batch N rows i, C negatives j per row)

Sample: rows (s_i, u_i, s'_i) from the preimage-augmented dataset; hindsight goal g_i = a
state later on the same trajectory (geometric horizon, OGBench GCDataset convention, plus a
fraction of random-state goals); negatives s+_j = next states of C other rows; the positive
column is s'_i itself.

1. Coefficient: c_i = w*(g_i) (stop-grad into 2 and 3).
2. Bellman fit of phi, b (contrastive TD, the repo's `contrastive_loss` form on an N x (C+1)
   matrix whose column 0 is the positive s'_i):
       M_ij   = phi(s_i,u_i,s+_j)^T c_i + b(s_i,u_i,s+_j)
       u'_i   = argmax_{m<=8} [min_P] phi_bar(s'_i,u_m,g_i)^T c_i + b_bar(s'_i,u_m,g_i)     (target nets)
       Mbar_ij = phi_bar(s'_i,u'_i,s+_j)^T c_i + b_bar(s'_i,u'_i,s+_j)                       (min_P, stop-grad)
       loss_M = contrastive(M, gamma * Mbar)
   Descent on phi, b only.
3. Coefficient improvement (h only, phi/b stop-gradded):
       obj  = (1/N) sum_i phi(s_i,u_i,g_i)^T w*(g_i) + b(s_i,u_i,g_i)
       viol_ij = max( -( phi(s_i,u_i,s+_j)^T w*(g_i) + b(s_i,u_i,s+_j) ), 0 )
       pen  = (1/NC) sum_ij l(s_i,u_i,s+_j) * viol_ij          (l stop-gradded)
       loss_h = -obj + constraint_coef * pen
   Descent on h.
4. Multipliers (when constraint_coef > 0): ascent on l of pen with phi, b, h fixed; l >= 0 by
   softplus. Learning rate lr_l <= lr_h.
5. Polyak targets for phi, b (tau 0.01).

## Test time

G = rewarding next states of the relabel batch (10k rows, r+1 = 1), subsampled to K_g = 32.
    w = sum_{g in G} w*(g) / || sum_{g in G} w*(g) ||
    u*(s) = argmax_{m<=64} [min_P] (1/K_g) sum_{g in G} ( phi(s,u_m,g)^T w + b(s,u_m,g) ),   action = G(s,u*)

## Tests (TDD, CPU, tiny dims)

- hindsight goals lie on the same trajectory and after the row; random-goal fraction honoured.
- w*(g) has unit norm; M is affine in w* (M(c1)+M(c2) = 2 M((c1+c2)/2)).
- backup latent is one of the 8 candidates and is the argmax of the pessimistic target Q_g.
- loss_M gradient reaches phi, b only; loss_h gradient reaches h only; pen ascent raises l on
  violated triples and leaves it unchanged where viol = 0.
- constraint_coef = 0 gives loss_h = -obj exactly.
- update runs and is finite; sample_actions returns a clipped action of the right shape;
  goal-set inference produces unit-norm w and K_g goals from rewarding rows only.

## First launch diverged; scale anchor added (2026-09-17 01:00-01:40)

Jobs 2518981-86 (launched 00:58) were cancelled at ~15k steps. At 5k/10k/15k steps the
measure at the positive column read 2.4e5 / 4.4e5 / 3.3e5 (nocon sd0), `td_target_absmean`
5.9e3 / 1.0e4 / 1.1e4, every negative triple violated (`viol_frac` 0.998-1.000); the con arm's
multipliers ran 1.3e3 -> 5.0e3 -> 1.5e4 with `viol_frac` swinging 0.03 -> 0.07 -> 0.999. The
2P and EMaQ runs read `td_target_absmean` 230-400 at the same step.

Cause: the spec removed the state basis and its orthonormality term and put no scale
control in their place. A general phi(s,u,s+) sets every s+ column independently, so unlike
psi^T f(s+) nothing couples the positive column to the negatives, and the contrastive term
-2 M(s,u,s') is unbounded below.

Fix (commit `cfbb285`, tests first): phi(s,u,s+) on the sphere of radius sqrt(D); w*(g) on the
sphere of radius sqrt(D) (the note's h/||h|| up to the constant radius, the same radius the
task vector uses elsewhere); b bounded by D tanh(b/D). Hence |M| <= 2D = 256, the order of
the repo's `psi_bound_scale` 200. Nothing else changed. Re-smoke (300 steps, CPU,
constraint_coef 1): measure at the positive 4-75, negatives -16 to 58, td_target 20-58,
w_norm 11.314, viol_frac 0 at five of six logs, multipliers 0.8-5.4.

Relaunch 01:11 (jobs 2518992-94 nocon, 2518995-97 con). Telemetry at 10k steps, anchored:

| arm | td_target_absmean | M at positive | M at negatives | obj | viol_frac | mult_mean |
|---|---|---|---|---|---|---|
| nocon sd0/1/2 | 63 / 66 / 65 | 241 / 240 / 227 | -57 / -60 / -58 | 1.0 / 5.4 / 2.6 | 0.999 x3 | (unused) |
| con sd0/1/2 | 17 / 20 / 15 | 253 / 246 / 253 | +9.9 / +0.5 / +8.7 | 42 / 24 / 38 | 0.003 / 0.397 / 0.006 | 660 / 1860 / 684 |

Bounded, finite, `w_norm` 11.3. The measure at the positive sits at the cap 2D = 256 in both
arms (b saturates); the negatives are pushed negative without the constraint and held at or
above zero with it. Whether a capped measure still ranks latents is what the 250k evals answer.

## Result (2026-09-17): negative

All 6 runs finished at 1M. TD stayed stable throughout (measure capped at 2D, `w_norm` 11.31).
Five-task eval500, 500 episodes/task, 3 seeds, mean ± 95% CI across seeds:

| arm | 250k | 500k | 750k | 1M |
|---|---|---|---|---|
| nocon | 0.075 ±0.078 | 0.057 ±0.105 | 0.002 ±0.003 | 0.002 ±0.003 |
| con | 0.118 ±0.131 | 0.007 ±0.010 | 0.004 ±0.004 | 0.029 ±0.031 |

Per-seed at the best cell (con 250k): 0.000 / 0.231 / 0.123.

Pre-registered readings resolved:
- five-task > 0.328 at any step: NOT met (max 0.118).
- both arms <= 0.284 with stable TD: MET. The goal-indexed affine successor measure over the
  frozen flow's latents does not carry a goal-reaching value on cube.
- con vs nocon: equal within noise at 250k, both decay to near-zero later. The non-negativity
  constraint does not rescue acting.

Both arms act better at 250k than at 1M: more TD makes the capped measure worse for ranking
latents. The capped measure answer to the 09-17 01:40 question is no. Best cell (0.118) is at
the BC level (0.111) and inside its CI. Comparators: EMaQ 0.282, 2P-GPI 0.328, FB 0.496,
HILP 0.742.

Eval-pipeline note (for reruns): eval with `MODE=psmgoal` (not `psmflow`; the checkpoints are
`agent=psmgoal` and the eval asserts the run's `flags.json` agent matches) and export
`PSM_REPO` explicitly (the sbatch requires it and `--export=ALL` only carries the submitting
shell's env). The original watcher had neither and submitted nothing.
